# LEDGERLY AI ACCOUNTANT - PHASE 3
# NATURAL LANGUAGE ACCOUNTING ENGINE

OBJECTIVE:

Transform Ledgerly from an AI recommendation engine into a conversational accounting assistant that understands natural language and can answer questions using live accounting data.

Ledgerly should become an accountant that users can talk to in plain English.

IMPORTANT:

Ledgerly must answer questions using REAL LedgerPoint data.

Do not generate generic AI responses.

Always query the application's database before generating a response.

The AI must explain its reasoning.

The AI must never invent accounting data.
