PHASE 4 – AI VAT ASSISTANT

Build the next major component of LedgerPoint: an AI VAT Assistant.

The objective is to make LedgerPoint capable of acting like an intelligent VAT accountant.

The AI VAT Assistant should continuously analyse the company's accounting data, identify VAT issues, calculate VAT positions, explain them clearly, highlight transactions that may require attention, and prepare a VAT return for user review.

IMPORTANT:

This must build on the existing LedgerPoint application.

DO NOT rebuild existing functionality.

DO NOT replace existing accounting, banking, reconciliation, invoice, purchase, customer, supplier, dashboard or AI functionality.

Reuse the existing:

- database
- accounting engine
- transaction models
- invoice models
- purchase/bill models
- chart of accounts
- VAT/tax fields
- AI service
- authentication
- dashboard components
- notification system
- existing design system

Before changing anything:

1. Inspect the existing accounting architecture.
2. Identify how VAT is currently stored.
3. Identify how sales invoices calculate VAT.
4. Identify how purchase bills calculate VAT.
5. Identify how credit notes calculate VAT.
6. Identify how bank transactions are categorised.
7. Identify the existing AI Accountant architecture.
8. Identify any existing VAT functionality.
9. Reuse existing services wherever possible.

Do not create duplicate models if an equivalent model already exists.

--------------------------------------------------
32. IMPORTANT ACCOUNTING SAFETY RULE

The AI is an assistant, not the accounting ledger.

The accounting engine remains the source of truth.

AI must NEVER:

- Invent VAT figures
- Invent transactions
- Invent invoices
- Invent VAT rates
- Invent HMRC rules
- Automatically change accounting records
- Automatically submit a VAT return
- Automatically make a tax election
- Automatically apply a complex VAT treatment
- Automatically write off VAT
- Automatically post adjustments

All material accounting changes require deterministic logic and/or explicit user approval.
