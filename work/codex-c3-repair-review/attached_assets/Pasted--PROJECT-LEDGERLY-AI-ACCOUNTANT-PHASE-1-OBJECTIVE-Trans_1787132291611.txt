# PROJECT: LEDGERLY AI ACCOUNTANT (PHASE 1)

## OBJECTIVE

Transform Ledgerly from an AI chatbot into an embedded AI Accountant that actively assists users throughout the accounting workflow.

The AI should not simply answer questions.

It should:

- Analyse transactions
- Reconcile bank statements
- Identify missing revenue
- Suggest invoice matches
- Categorise transactions
- Detect anomalies
- Identify bookkeeping issues
- Generate accounting insights
- Prepare actions for user approval

IMPORTANT:

The AI must NEVER automatically post transactions, create journals, delete records, or submit VAT returns.

All AI actions must require user approval.

# PHASE 1 FEATURE: INTELLIGENT RECONCILIATION

When a bank statement is imported, reconciliation should start automatically.

For every imported bank transaction:

1. Search for all unpaid invoices.

2. Compare:

- Transaction amount
- Customer name
- Reference number
- Invoice amount
- Transaction date
- Payment date

3. Generate a confidence score.

---

# MATCHING LOGIC

Use the following scoring system:

## Exact amount match

+50 points

## Customer name match

+20 points

## Invoice number found in reference

+20 points

## Date within 7 days

+10 points

Maximum score:

100 points

# AI ACCOUNTANT RULES

The AI must NEVER:

❌ Post transactions

❌ Create journals automatically

❌ Create invoices automatically

❌ Delete records

❌ Submit VAT returns

❌ Modify historical transactions

The AI may ONLY:

✅ Analyse

✅ Suggest

✅ Explain

✅ Recommend

✅ Prepare actions

The user must always approve the final action.
