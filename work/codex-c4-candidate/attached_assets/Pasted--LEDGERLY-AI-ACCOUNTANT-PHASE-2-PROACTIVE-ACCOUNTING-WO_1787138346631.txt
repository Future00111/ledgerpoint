# LEDGERLY AI ACCOUNTANT - PHASE 2
# PROACTIVE ACCOUNTING WORKFLOWS

OBJECTIVE:

Transform Ledgerly from an AI reconciliation tool into a proactive AI Accountant that continuously monitors the ledger, identifies issues and prepares accounting actions for approval.

IMPORTANT:

The AI must NEVER automatically:

- Post transactions
- Create journals
- Submit VAT returns
- Delete transactions
- Modify historical data
- Make accounting decisions without user approval

The AI may ONLY:

- Analyse
- Recommend
- Explain
- Prepare actions
- Create a review queue

All actions must be approved by the user.
