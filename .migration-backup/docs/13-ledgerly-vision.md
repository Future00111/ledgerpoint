# 13 — Ledgerly Vision

> Our mission is to build the accounting software that business owners actually enjoy using.

This is Ledgerly's guiding vision. It sits above every principle, feature and decision in Project Atlas. When any choice is unclear, return here first.

---

## 1. The mission

Build the accounting software that business owners actually enjoy using.

Enjoyment is the north star. If a feature makes the product more powerful but less enjoyable, it is the wrong feature.

---

## 2. What accounting should feel like

- **Simple** — the everyday tasks a business owner does should take seconds, not minutes.
- **Intelligent** — Ledgerly does the thinking: it suggests, explains, and remembers.
- **Effortless** — the software fades into the background; the work is what stays in view.

---

## 3. How we treat the user

- Ledgerly should **reduce stress, not create it** (see [11 — Calm Computing](./11-calm-computing.md)).
- Every feature should **save time, increase confidence, and help users understand their business**.
- Technology should **disappear into the background**.
- Users should spend **less time learning software and more time running their business**.

---

## 4. How we measure success

Success is **not** measured by the number of features.

Success is measured by **how easy Ledgerly makes running a business**.

A product with fewer features that a owner uses confidently every day beats a product with more features that no one understands.

---

## 5. The vision in one line

> Simple. Intelligent. Effortless. Enjoyable.

---
