# Definition of Done

> A feature is only complete when every check below passes.
> This document is mandatory and sits beneath the Ledgerly Manifesto within Project Atlas.

---

A feature is only considered complete when it satisfies **ALL** of the following:

- [ ] Aligns with the Ledgerly Manifesto
- [ ] Aligns with the Product Principles
- [ ] Meets the Product Requirements Document (PRD)
- [ ] Meets Technical Architecture standards
- [ ] Meets UI/UX Design System standards
- [ ] Accessible on Desktop, Tablet and Mobile
- [ ] Searchable through Ask
- [ ] Supports permissions correctly
- [ ] Includes audit logging where required
- [ ] Contains no developer-facing information
- [ ] Uses business-friendly language
- [ ] Includes loading states
- [ ] Includes empty states
- [ ] Includes error handling
- [ ] Includes success notifications
- [ ] Includes documentation updates
- [ ] Has been tested

---

Only after **all** checks pass may a feature be marked as complete.
