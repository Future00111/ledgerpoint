description: Deliberate pause boundary, frozen accounting-core scope, and required resumption sequence for TR-01.

Preserve every frozen TR-01 candidate as published. Development qualification
is not governance activation, activated qualification, production readiness or
Phase A approval. Consult the latest evidence/approval records rather than
assuming the original candidate's pending gates still describe successor
development status. Package-level or automated review must not be described
as fresh independent-human approval of an exact published successor.

**Why:** The owner explicitly limits successor qualification to development and
requires frozen candidates and local work to remain preserved. A successful
development run does not authorize the next governance or deployment stage.

**How to apply:** Keep canonical posting, double-entry persistence,
authority-provider architecture, financial-year and period authorities,
configuration-version authorities, canonical mappings, journal immutability,
transition-principal/protected-owner controls, migration/cutover architecture,
and canonical-posting database security frozen unless a separately approved
change requires otherwise. Normal product development may continue outside
that boundary. Workspace synchronization must preserve local changes and
distinguish a composite integration tree from a byte-exact qualified candidate.
Consult the latest approval record before live configuration; remaining
governance, activation and production gates require separate authorization.

For synchronization across divergent workspace/main/candidate histories,
anchor an integration branch in the current workspace history and selectively
import reviewed source paths rather than replacing the workspace wholesale.

**Why:** The owner approved exact runtime/producer imports while requiring all
existing Replit work and historical evidence to remain preserved. Main and the
qualified runtime branch need not represent the same complete project layout.

**How to apply:** Reassess the current divergence, preserve a base ref and
ignored evidence separately, verify imported bytes against their exact sources,
and give the composite integration its own identity and local validation record.
